Parsing is driven by two separator fields:

  • Field Separator — splits the line into chunks (e.g. , or :).
  • Name/Value Separator — splits name from value within each chunk (e.g. = or :). Leave blank for positional mode.

Three resulting modes:

  • Positional (Name/Value Sep blank) — 23.5,8.1,0.95 — column index maps to a variable name.
  • Key=Value (Name/Value Sep ≠ Field Sep) — DO=8:salinity=34 (field sep :, name/val sep =) — source label maps to a variable name.
  • Alternating pairs (Name/Value Sep = Field Sep) — ph,6,temp,5 (both ,) — names and values alternate.

The Variable Name (max 10 characters) is used identically for:

  • Mavlink2Rest — NAMED_VALUE_FLOAT with this name. Appears in ArduPilot .BIN logs.
  • Cockpit WebSocket — variable_name=value to the data-lake.
  • CSV Log — column header in downloaded logs.
